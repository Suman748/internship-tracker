# Week 3: React API integration and Create/Edit flow

## React API integration
- Task list is connected to the Spring API (GET /api/tasks)
- Loading, empty and error (with Retry) states are visible

## Create and edit flow
- Create (POST), edit (PUT) and delete (DELETE with confirmation dialog) from the UI
- Form clears after create; title validation on the client
- Browser-to-database CRUD works; data survives an API restart (docs/week3/db-after-restart.json)

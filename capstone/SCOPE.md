# Internship Task Tracker - Capstone Scope

## Problem
Interns and mentors track daily assignments in spreadsheets, which makes status, links and feedback hard to follow. This app gives one place to manage tasks, update status and review progress.

## Tech stack
React + Spring Boot + PostgreSQL

## In scope
- Create, view, edit and delete tasks
- Update task status
- Filter tasks by status and show a completed count
- Form validation and clear error messages
- README with setup steps and demo

## Out of scope
- User login and roles
- Notifications and email
- File uploads

## Risks / assumptions
- Frontend (react-task-dashboard) and API (tracker-api) can be connected without major rework
- PostgreSQL is available locally for development
